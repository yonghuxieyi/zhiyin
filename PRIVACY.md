# Runse Privacy Policy

Runse refines and translates text through the provider you configure in the app.

## Data Processed

When you run a refine or translate action, the selected text, selected action, and related prompt options are sent to the active AI provider so it can return a result. Provider responses and token counts may be stored locally in the app history.

## API Keys

Provider API keys are stored in the iOS Keychain. Runse includes a built-in default provider key for the default experience, and you can add your own provider keys in the app.

## Local Storage

Runse stores providers, prompts, settings, and history on your device. These records are not uploaded by Runse to a Runse-operated server.

## Third-Party Providers

AI providers process requests under their own terms and privacy policies. Only send text that you are comfortable sharing with the active provider.

## Analytics and Tracking

智音 does not use advertising identifiers and does not track you across apps or websites.
