## 功能（v1）
- 长文翻译：粘贴长文自动切段、逐段流式翻译、进度显示，术语表保证同一术语前后译法一致。
- 语音翻译：豆包流式语音识别 2.0 + 语音合成 2.0，自动识别中/英文、翻成另一种并朗读。
- 拍照/图片翻译：苹果 Vision 端侧认字（中文 accurate 模式），认出的文字进翻译管线。
- 模型选择：设置里可换模型，分国内云端 / 本地离线 / 国外云端三组；没网时云端组不可选；各家 Key 存手机钥匙串。
- 语音的 AppID 和 Access Token 只存钥匙串，不进代码；未配置时语音页会提示去配置。
